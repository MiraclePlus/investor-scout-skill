# 融资 Playbook 精华：从 Promise 到 Proof

> 早期融资方法论

## 核心心智模型

第二笔钱的本质：从 promise 到 proof，融资态度的转移。

- 第一笔钱：看人、方向、故事。核心问题是"这件事有没有可能？"
- 第二笔钱：看证明、节奏、推进能力。核心问题是"为什么是你，为什么现在已经开始成立？"

融资的目标是把投资人从"默认不行"推进到"愿意内部猛推"，直到钱到账。

## 投资人状态转移模型

| 状态 | 创始人要做的事 | 典型证据 |
|------|-------------|---------|
| 默认不行 | 让投资人记住你，愿意听完主线 | 一句话 Pitch、Hook、清晰品类定义 |
| 记住你 | 让投资人愿意验证 | Demo、早期数据、客户访谈、技术 demo |
| 愿意验证 | 让投资人相信你能过内部流程 | FAQ、Data Room、竞品分析、单位经济、客户 reference |
| 内部猛推 | 赋能 Champion | Champion Memo、清晰融资方案、Next Step |
| 钱到账 | 管理 TS/DD/SPA/打款 | 律师、财税、公司资料、签字流程 |

## Ready Scorecard（融资准备度自检）

不需要每项满分，但至少有 1-2 项足够尖锐，且没有致命短板。

| 维度 | 2 分标准 |
|------|---------|
| 精干团队 | 核心能力完整；创始人能深度解释技术、用户、商业和战略 |
| 精准定位 | 有明确 ICP、使用场景和购买动机 |
| 惊艳 Demo | Demo 能产生 Aha Moment；不是 PPT 概念 |
| 实质进展 | 至少一条 proof 能触发内部流程（付费 POC、稳定留存、真实部署） |
| Runway | 融资启动时仍有 9 个月以上；到账后覆盖 18-30 个月 |

**底线**：如果需要用"赛道很热"来掩盖 Scorecard 的空白，说明还没 Ready。

## 不同类型公司的 Proof 要求

| 公司类型 | 必须证明 | 不要只讲 |
|---------|---------|---------|
| AI Agent/App | 工作流渗透率、留存、付费闭环、客户 ROI | 模型能力强、Demo 很酷 |
| AI Infra/DevTools | 真实企业部署、开源活跃度、生产稳定性 | 架构很新、理念先进 |
| 智能硬件/机器人 | 真实场景、量产路径、BOM、订单/试点 | 原型机惊艳、视频好看 |
| 前沿硬科技 | 技术 milestone、人才密度、产业落地预期 | 论文厉害、方向重要 |
| 企业 SaaS | 预算迁移、续费/扩容、关键岗位依赖 | 客户都说有兴趣 |
| 消费/2C | 真实增长、留存、复购、单位经济 | 流量很大、KOL 背书 |

## 融资方案设计公式

```
目标融资额 = 预计月度 Net Burn × 目标 Runway + 10%-20% 安全资金 − 当前现金
```

- 目标 Runway：18-30 个月
- 融资周期：早期常见 6-9 个月
- 稀释区间：10%-20% 为常见区间

## 融资材料清单

| 组件 | 解决的问题 |
|------|-----------|
| 一句话 Pitch | 你是谁，为什么继续听 |
| BP/Pitch Deck | 逻辑自洽，市场够大 |
| Demo/数据看板 | 是否真的做出来了 |
| FAQ | 尖锐问题能否快速回答 |
| Data Room | DD 能否快速推进 |
| Investor CRM | 流程能否被 CEO 管理 |

## Demo Day Playbook

**之前**：知道你要证明什么，不只是知道你要讲什么。
**当天**：目标不是当场拿钱，而是建立高质量投资人漏斗。
**之后**：把融资当成 CEO 亲自管理的销售流程。

24 小时跟进原则：假设投资人已经忘记了你。必须重新说清公司、亮点和下一步请求。

## 2026 资本地图

| 钱的类型 | 它真正想要 | 创始人要判断 |
|---------|-----------|------------|
| 财务 VC | 回报、大退出、极高增长 | 是否理解你的 outlier 路径 |
| 人民币/国资 | 产业落地、产值、税收、就业 | 反投比例、落地承诺、合规 |
| 产业资本/CVC | 战略协同、供应链安全 | 是否限制未来拓展路径 |
| 海外资本 | 全球市场、美元退出路径 | 地缘、数据出境、架构合规 |

**原则**：优先拿与下一轮融资路径兼容的钱。最常见的坑不是没融到，而是拿错了约束。
