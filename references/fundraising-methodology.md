# 融资 OS：排 / 聊 / 推 / 谈

> 早期融资方法论

## 三波约聊策略

| 波次 | 目标 | 对象 | 关键动作 |
|------|------|------|---------|
| Wave 1 预热 | 测试故事，收集核心问题 | 关系好的老股东、友好投资人 | 打磨 FAQ，发现漏洞。**不要先见最想拿的钱** |
| Wave 2 进攻 | 拿 TS，制造势能 | 最匹配、有决策权的投资人 | 集中火力；每次明确 Next Step |
| Wave 3 补充 | 备选方案、优化条款 | 跟风型、CVC、国资/产业 | 用前两波势能推动决策 |

## Investor CRM 必备字段

| 字段 | 用途 |
|------|------|
| 投资人/基金/职级/联系方式 | 基础信息 |
| 近期是否活跃出手/基金是否有钱 | 过滤僵尸 VC |
| 投过哪些相似项目/是否投过竞品 | 专业度、利益冲突 |
| 偏好阶段/单笔额度/能否领投 | 匹配本轮 |
| 真实兴趣信号 | 要求测试账号/数据/客户访谈 |
| 核心疑虑 | 团队/市场/产品/估值 |
| Champion 是谁 | 内部推动者 |
| 下一步和时间点 | 不允许只写"保持联系" |
| 状态 | 热/暖/冷/Pass/Zombie/Tourist |

## 不同会议的不同目标

| 会议类型 | 目标 | 不要做什么 |
|---------|------|-----------|
| 初次见面 | 让对方记住你，拿到下一次会议 | 陷入过度技术细节 |
| 深度沟通 | 消除疑虑，建立信任 | 回避尖锐问题 |
| 合伙人会前 | 帮 Champion 内部推进 | 只重复 BP |
| 休闲会面 | 建立关系，获取真实反馈 | 过度推销 |

## 初次会面 20 分钟结构

| 时间 | 内容 | 目标 |
|------|------|------|
| 0-5 min | Why Now + 痛点 | Hook：抓住注意力 |
| 5-10 min | 产品解法 + Demo | Aha Moment |
| 10-15 min | 为什么是我们 | Team & Moat |
| 15-20 min | Traction + 融资诉求 | Proof + Next Step |

## 真信号 vs 假信号

| 真兴趣 | 假兴趣/婉拒 |
|--------|------------|
| 追问核心业务细节 | 宏观肯定"方向很好，保持联系" |
| 主动要求验证（测试账号/后台数据） | 拖延"等数据跑出来再看" |
| 明确下一步和时间 | 模糊"内部再讨论" |
| 要求客户访谈/财务数据/条款 | 只聊行业不回到公司 |

## Champion 子弹清单

| 给 Champion 的子弹 | 具体材料 |
|------------------|---------|
| 一句话内部转述 | 30 秒向合伙人解释为什么值得看 |
| 最强 proof | 客户、数据、订单、部署案例 |
| 竞品分析 | 为什么不是大厂做 |
| 客户/专家 reference | 证明需求真实 |
| 风险与应对 | 主动写清最尖锐的 3 个风险 |
| 融资方案 | 融资额、估值、出让比例、时间表 |

## BATNA（最佳替代方案）

谈判前必须写清：

| 项目 | 内容 |
|------|------|
| 估值底线 | 低于多少绝不接受 |
| 稀释底线 | 最多出让多少 |
| 融资额底线 | 最少到账多少能撑 12-18 个月 |
| 条款底线 | 不可接受：强回购、业绩对赌、过长排他 |
| 替代方案 | 其他 TS / 老股东 bridge / 收入回款 |

## 会后 24 小时跟进模板

> "感谢您今天的时间。根据您关心的【问题】，我补充了【材料/数据】。下一步如方便，是否可以在【时间】安排与【合伙人/技术同事】的深聊？"

**原则**：创始人尊重投资人的内部流程，但不把推进节奏完全交给投资人。没听到明确 Yes，就按 No 处理。

## Runway 与动作变形

| Runway | 含义 | 动作 |
|--------|------|------|
| 18-30 月 | 理想状态 | 从容融资 |
| 9-18 月 | 可控 | 启动融资准备，收缩非核心 |
| 6-9 月 | 红色预警 | 融资和降本并行 |
| <6 月 | 危险 | 立即降 burn，考虑 bridge/裁员 |

## 90 天执行计划模板

| 模块 | 必须写清楚 |
|------|-----------|
| 3 个核心目标 | 最能提高融资成功率的 proof |
| 每周指标 | 看什么数字，谁负责 |
| 资源分配 | 谁跑业务，谁支持融资 |
| 降本预案 | 30/60/90 天无进展分别削减什么 |
| 回款/桥接 | 客户提前回款 / 老股东 bridge |

## 每周融资复盘

- 本周见了多少家？热/暖/冷分别多少？
- 哪些投资人出现真兴趣信号？
- 共同疑虑是什么？
- BP 哪几页需要改？
- FAQ 新增哪些问题？
- 是否出现 Champion？需要什么子弹？
- 下周最关键 3 个 Next Step？
- 业务 proof 是否继续增长？
- 现金 runway 是否变化？
